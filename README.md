# Клиника

Google Sheets билан ишлайдиган қабул, навбат, чек, ётоқхона ва қарз ҳисоби тизими.

- `index.html`, `style.css`, `app.js` — сайт
- `Code.gs` — Google Apps Script (Sheets ичига қўйилади)

## Бўлимлар
- **Қабул** — бўлим бўйича навбат рақами ва чек, қисман тўлов (қарз)
- **Рўйхат** — кунлик қабуллар, чекни қайта чиқариш, бекор қилиш
- **Ётоқхона** — беморни ётқизиш, кунлик муолажалар, аванс, чиқариш ва якуний ҳисоб
- **Қарзлар** — қарздорлар рўйхати ва қарз тўлови
- **Ҳисобот** (админ) — касса тушуми, бўлимлар, докторлар улуши, қарзлар

## Code.gs ни янгилаш
Apps Script'да кодни алмаштиринг → Deploy → Manage deployments → Edit → **New version** → Deploy
(Execute as: Me, Who has access: Anyone). Янги варақ ва устунлар биринчи сўровда ўзи яратилади.
